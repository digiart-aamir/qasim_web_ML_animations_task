Step 1 · The idea

What is regression?

Regression learns a rule from examples to predict a numeric outcome. A linear model combines input features with learned weights: each weight describes how the prediction changes as that feature changes, holding the others fixed.

ŷ = b + β₁x₁ + β₂x₂ + ··· + βₚxₚ
Lasso extends linear regression with an L1 penalty. It can shrink weak feature weights to exactly zero, making the fitted model easier to inspect.

Step 4 · Objective

The Lasso objective

The fit balances two goals. The first term rewards predictions close to observed values; the second charges for large coefficients. Increasing α makes that complexity cost matter more.

MSE fit: (1 / 2n) Σ(yᵢ − ŷᵢ)² + penalty: α · Σ|βⱼ|
The intercept b is not penalized. Feature standardization makes coefficient shrinkage comparable across numeric input scales.
Step 5 · Soft-thresholding

How a coefficient becomes zero

Coordinate descent applies soft-thresholding to each coefficient update. Values inside the interval [−α, α] are set to zero; larger values are pulled toward zero.

soft(2, 1) = 1
Step 6 · Optimization

Coordinate descent, one weight at a time

The solver cycles through features, updates one coefficient while holding the others fixed, and repeats until changes become small. Use the iteration pager in the hero diagram to inspect saved model states.
