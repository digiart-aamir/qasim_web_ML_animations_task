Lasso objectiveCoordinate descent

J(b, β) = (1 / 2n) × Σᵢ (yᵢ − ŷᵢ)² + α Σⱼ |βⱼ|

ŷᵢ = b + Σⱼ βⱼxᵢⱼ. Here n is the number of training observations, yᵢ is the actual target, ŷᵢ is the prediction, α controls L1 regularization, and βⱼ are coefficients on the preprocessed features. The intercept b is fit separately and is not included in the penalty. Coordinate descent applies soft-thresholding to each coefficient until changes converge. The fitted equation converts coefficients back to original feature units; coefficient and alpha-comparison tables show the penalized β values.

Lasso Regression learning guideConcepts and examples

What is regression?

Regression predicts a numeric outcome from input features. For example, estimate a home's price from its area and age. A linear model writes that estimate as ŷ = b + Σ βⱼxⱼ.

What is Lasso Regression?

Lasso is linear regression with an L1 penalty on feature coefficients. It fits the data while discouraging unnecessarily large weights, and can set some weights exactly to zero.

What is L1 regularization?

The penalty is the sum of absolute coefficients, Σ |βⱼ|. The dashboard minimizes (1 / 2n) Σ(yᵢ − ŷᵢ)² + α Σ|βⱼ|; the intercept is not penalized.

Why use Lasso?

It can reduce over-reliance on weak predictors, improve generalization, and produce a smaller, easier-to-inspect model when many candidate features are available.

How does the algorithm work?

Coordinate descent updates one coefficient at a time while holding the others fixed. Soft-thresholding applies the L1 penalty; the process repeats until coefficient changes are small.

What does alpha control?

α sets penalty strength. At zero, the L1 penalty is absent. Larger values shrink more coefficients, possibly to zero; too much regularization can underfit.

How does feature selection happen?

For a coefficient update, Lasso uses soft-thresholding: sign(z) max(|z| − α, 0). Values within the threshold become exactly zero, removing their linear contribution.

Advantages and limitations

Advantages: sparse models and reduced variance. Limitations: it assumes additive linear effects, is sensitive to feature scaling, and may select one of several highly correlated predictors unpredictably.

Real-world applications

Lasso is useful for selecting candidate signals in forecasting, estimating prices or demand, analyzing survey outcomes, and reducing large sets of measurements before interpretation.
