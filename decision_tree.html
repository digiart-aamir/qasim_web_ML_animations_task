01 · Core Intuition

How a Decision Tree Partitions Space

Unlike linear models or support vector machines that separate classes using angled hyperplanes, a standard CART decision tree builds a hierarchy of simple axis-aligned threshold tests of the form $x_j \le t$. Geometrically, each split slices a rectangular region of the feature space perpendicular to a single coordinate axis, repeating recursively until every terminal region (leaf) is sufficiently pure.

Root & Internal Nodes

Each internal node tests one feature $x_j$ against a learned threshold $t$. Samples satisfying $x_j \le t$ route to the Left Child (True branch); all others route to the Right Child (False branch).

Terminal Leaf Nodes

When a stopping criterion triggers (purity achieved, max_depth reached, or too few samples), recursion stops. The leaf predicts the majority class (classification) or sample mean $\bar{y}$ (regression).

02 · Mathematical Foundations

Impurity Measures & Information Gain

At every node $t$ containing $N_t$ training samples across $K$ classes, let $p_{t,k} = \frac{1}{N_t}\sum_{i \in t}\mathbb{I}(y_i = k)$ denote the empirical proportion of class $k$. A node is pure ($I(t) = 0$) when all samples belong to a single class, and maximally impure when classes are uniformly mixed.

1. Gini Impurity (CART Default)
$$G(t) = 1 - \sum_{k=1}^{K} p_{t,k}^2$$

Measures the probability of misclassifying a randomly chosen sample in node $t$ if it were randomly labeled according to the node's class distribution. Binary range: $[0, 0.5]$.

2. Shannon Entropy (ID3 / C4.5)
$$H(t) = -\sum_{k=1}^{K} p_{t,k} \log_2\big(p_{t,k}\big)$$

Measures average information content (in bits) required to identify a sample's class. Binary range: $[0, 1.0]$. Uses convention $0 \log_2 0 = 0$.

3. Weighted Impurity Reduction (Objective Function)
$$\Delta I(t, j, s) = I(t) - \left( \frac{N_L}{N_t} I(t_L) + \frac{N_R}{N_t} I(t_R) \right)$$

CART greedily selects the feature $j^*$ and threshold $s^*$ that maximize $\Delta I(t, j, s)$ at the current node. For Regression Trees, $I(t)$ is replaced by Mean Squared Error: $\text{MSE}(t) = \frac{1}{N_t}\sum_{i \in t}(y_i - \bar{y}_t)^2$.

03 · Criteria Comparison

Splitting Criteria Reference Table

Different tree formulations use distinct impurity functions. While Gini and Entropy yield identical trees in roughly 98% of practical cases, their computational profiles and bias toward multi-valued splits differ.

Criterion Formula Binary Max Computational Cost Primary Use Case
Gini Impurity $1 - \sum p_k^2$ 0.50 Fast (no logs) Default in scikit-learn CART; fast on large datasets
Shannon Entropy $-\sum p_k \log_2 p_k$ 1.00 Moderate ($\log_2$) Information-theoretic splits; slightly more balanced trees
Gain Ratio $\Delta H / \text{SplitInfo}$ 1.00 Moderate C4.5; penalizes high-cardinality categorical features
Variance / MSE $\frac{1}{N}\sum (y_i - \bar{y})^2$ Unbounded Fast Continuous target prediction (Regression Trees)
04 · Worked Example

Step-by-Step Numerical Split Evaluation

Suppose we have $N = 8$ samples with two continuous features $(X_1, X_2)$ and binary labels $Y \in \{A, B\}$: 4 Class A and 4 Class B. The root node Gini impurity is: $$G(\text{Root}) = 1 - \left(\frac{4}{8}\right)^2 - \left(\frac{4}{8}\right)^2 = 1 - 0.25 - 0.25 = 0.500$$ Below is the exact candidate evaluation table demonstrating how CART chooses the root split:

Candidate Split Left Group ($N_L$) Right Group ($N_R$) $G(\text{Left})$ $G(\text{Right})$ Weighted Gini Gain ($\Delta G$)
X₁ ≤ 2.5 2A, 0B (n=2) 2A, 4B (n=6) 0.000 0.444 0.333 +0.167
X₁ ≤ 4.5 ★ 4A, 1B (n=5) 0A, 3B (n=3) 0.320 0.000 0.200 +0.300 (Best)
X₂ ≤ 3.0 3A, 2B (n=5) 1A, 2B (n=3) 0.480 0.444 0.467 +0.033
X₂ ≤ 6.0 3A, 3B (n=6) 1A, 1B (n=2) 0.500 0.500 0.500 +0.000

Because X₁ ≤ 4.5 achieves the highest impurity reduction ($\Delta G = +0.300$), it becomes the root split. Its right branch ($0A, 3B$) is already pure ($G = 0.000$) and immediately forms a terminal leaf predicting Class B.

05 · Algorithm

CART Recursive Training Pseudocode

Finding the globally optimal decision tree is NP-complete. Therefore, CART uses a top-down greedy heuristic that evaluates every feature and every midpoint threshold at each node.

build_tree(samples, depth) 
function BUILD_TREE(D, depth):
  if PURE(D) or depth == max_depth or |D| < min_samples_split:
    return Leaf(prediction = MAJORITY_CLASS(D))

  best_gain = 0
  best_split = null

  for each feature j in {1 .. d}:
    thresholds = MIDPOINTS(SORTED_UNIQUE(D[:, j]))
    for each t in thresholds:
      D_left  = { x in D | x[j] <= t }
      D_right = { x in D | x[j] >  t }
      if |D_left| < min_samples_leaf or |D_right| < min_samples_leaf:
        continue

      gain = IMPURITY(D) - (|D_left|/|D|)*IMPURITY(D_left)
                         - (|D_right|/|D|)*IMPURITY(D_right)
      if gain > best_gain:
        best_gain = gain
        best_split = (j, t, D_left, D_right)

  if best_split == null:
    return Leaf(prediction = MAJORITY_CLASS(D))

  left_child  = BUILD_TREE(best_split.D_left,  depth + 1)
  right_child = BUILD_TREE(best_split.D_right, depth + 1)
  return Node(feature=j, threshold=t, left=left_child, right=right_child)
06 · Regularization & Pruning

Hyperparameters & Overfitting Control

An unconstrained tree can grow until every training point sits inside its own pure leaf—achieving 100% training accuracy while memorizing noise (high variance). Regularization is applied either via pre-pruning (stopping growth early) or post-pruning via minimal cost-complexity pruning: $$R_\alpha(T) = R(T) + \alpha |T|$$ where $R(T)$ is total leaf impurity, $|T|$ is the number of terminal leaves, and $\alpha \ge 0$ penalizes tree size.

Hyperparameter Type Effect When Tightened Typical Tuning Range
max_depth Pre-pruning Limits longest root-to-leaf path; prevents deep memorization 2 – 12 (or None in ensembles)
min_samples_split Pre-pruning Requires more data before allowing an internal node to split 2 – 20
min_samples_leaf Pre-pruning Ensures every terminal leaf represents a statistically stable region 1 – 15
max_features Subsampling Restricts candidate features per split; decorrelates trees in Random Forests $\sqrt{d}$ or $\log_2 d$
ccp_alpha Post-pruning Collapses weak branches whose gain fails to justify extra leaves 0.0 – 0.05 (via CV)
07 · Model Comparison & Complexity

Evolution, Complexity & Trade-Offs

Algorithm Split Structure Metric Continuous Features Pruning Method
ID3 (1986) Multi-way Entropy / Info Gain No (categorical only) None
C4.5 (1993) Multi-way / Binary Gain Ratio Yes (thresholding) Error-based post-pruning

Key Strengths

  • Zero feature scaling needed: Monotonic transformations (log, z-score) leave splits unchanged.
  • Ultra-fast inference: Predicts in $O(\text{depth})$ simple scalar comparisons.
  • Native interpretability: Every prediction converts directly into human-readable IF-ELSE rules.
  • Captures non-linear interactions: Naturally models XOR and hierarchical conditions.

Limitations

  • High variance / instability: Small perturbations in training data can alter the root split and entire tree.
  • Staircase boundaries: Diagonal boundaries require many axis-aligned steps to approximate.
  • Greedy optimality: Locally optimal splits do not guarantee a globally minimal tree.
  • Training cost: Exact split search scales as $O(d \cdot n \log n)$ per level.
