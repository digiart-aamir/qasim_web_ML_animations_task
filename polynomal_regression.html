Polynomial Theory & Mathematical Foundations

Polynomial regression extends linear regression to model arbitrary smooth non-linear curves. Below are the exact matrix systems, bias-variance tradeoffs, and mathematical formulations powering this analyzer.

Matrix Representation

The Vandermonde Design Matrix

Although polynomial regression produces a curved line, it is still mathematically a linear model because it is linear in the parameters $a_k$. By creating artificial polynomial powers of $X$, we construct the Vandermonde design matrix:

Design Matrix X:
X = [ 1, x₁, x₁², ..., x₁ᵈ ]
[ 1, x₂, x₂², ..., x₂ᵈ ]
[ ..., ..., ..., ..., ... ]
[ 1, xₙ, xₙ², ..., xₙᵈ ]
Vector Equation: ŷ = X · a
where a = [a₀, a₁, a₂, ..., aᵈ]ᵀ are the polynomial coefficients.
Numerical Optimization

Normal Equations & QR Decomposition

The standard least squares closed-form solution solves $(X^T X)\mathbf{a} = X^T \mathbf{y}$. However, directly computing $X^T X$ squares the condition number $\kappa(X)$, causing catastrophic floating-point cancellation for $d \ge 4$.

Standard Normal Eq: a = (XᵀX + λI)⁻¹ Xᵀ y

Householder QR Solver: X = QR
R · a = Qᵀ y ==> Backward substitution.
Preserves numerical precision without ever forming XᵀX!
Machine Learning Concept

The Bias-Variance Tradeoff

The choice of polynomial degree $d$ is the quintessential visual demonstration of the bias-variance dilemma:

  • Underfitting ($d = 1$ on curved data): High Bias. The model is too rigid to capture the genuine trend. Both training and testing error are high.
  • Sweet Spot ($d = 2$ or $3$): Optimal balance. Captures true curvature without fitting noise.
  • Overfitting ($d \ge 5$ with small $n$): High Variance. The curve bends unnaturally through every single noisy point. $R^2 \to 1.0$, but out-of-sample test error explodes.
High-Degree Pitfall

Runge's Phenomenon & Boundary Oscillation

In numerical analysis, Runge's phenomenon proves that fitting high-degree polynomials over equidistant points causes wild, violent oscillations near the boundaries of the interval $[X_{\min}, X_{\max}]$.

Try This In The Lab:
Select the "Runge's Oscillation" preset above and switch to Degree 5 or 6. Notice how the middle fits nicely, but the outer wings plunge or shoot up dramatically!

This is why high degrees ($d > 4$) are rarely used in production; practitioners use cubic splines or regularization instead.

Model Evaluation

Why Ordinary $R^2$ Lies With Polynomials

In standard regression, adding higher polynomial terms can never decrease $R^2$. Even adding purely random noise as $x^5$ will slightly increase $R^2$! To penalize unnecessary complexity, we use Adjusted $R^2$:

Adjusted R² Formula:
R²_adj = 1 - [ (1 - R²) · (n - 1) / (n - d - 1) ]

Where $n$ = sample size and $d$ = polynomial degree.
If adding $x^d$ does not improve the fit enough to offset the loss of a degree of freedom, $R^2_{\text{adj}}$ decreases!
Regularization

Ridge Shrinkage Penalty ($\lambda$)

To tame high-degree oscillations without discarding higher powers, Ridge regression adds an $L_2$ penalty $\lambda \sum_{k=1}^d a_k^2$ to the objective function:

Loss = Σ(yᵢ - ŷᵢ)² + λ · ||a||²₂

Drag the Ridge $\lambda$ slider in the lab above. As $\lambda$ increases, extreme coefficient swings are penalized, flattening aggressive oscillations into a stable, well-behaved curve.
